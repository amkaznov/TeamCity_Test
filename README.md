# TeamCity Test Framework

Сборник **лучших практик по написанию и организации автотестов на Java**.

## 📌 О проекте

Это практический сборник примеров и подходов, которые я использую при разработке автотестов. Здесь собраны решения для:
- структурирования тестового кода
- разделения тестов по типам
- управления тестовыми данными
- организации фреймворка

## 🛠 Технологии

- **Java 17+**
- **TestNG**
- **Selenium** + **Selenoid**
- **REST-assured** (для API тестов)
- **Maven**

## 📁 Структура

```
src/test/java/org/example/
├── api/          # примеры API тестов
└── ui/           # примеры UI тестов
```

## 💡 Ключевые моменты

✅ **Разделение ответственности** — API и UI тесты отдельно  
✅ **Чистота данных** — удаление только созданных сущностей  
✅ **Модульность** — переиспользуемые компоненты  
✅ **Логирование** — понятные сообщения об ошибках  
✅ **Page Object Model** — для UI тестов
